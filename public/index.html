      连接浏览器与 DeepSeek

      01

      连接 DeepSeek

      尚未检查密钥

      Windows 使用当前账户加密保存密钥，浏览器扩展无法读取它。连接测试会产生少量 API 用量。

      02

      安装并配对浏览器扩展

      1. 打开 Edge 的扩展管理，启用“开发人员模式”。
      2. 点击“加载解压缩的扩展”（Load unpacked），选择项目中的 extension 文件夹。
      3. 点 Edge 工具栏的求职助手图标，在弹窗的“本地配对码”中粘贴，点击“保存并连接”。
      4. 登录 BOSS，打开岗位列表或聊天页并刷新。

      也可点“显示”，选中配对码后按 Ctrl+C，在求职助手弹窗中按 Ctrl+V。

      此码仅供扩展采集和执行任务；请在本机控制台修改设置。
